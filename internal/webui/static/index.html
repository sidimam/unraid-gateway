Connect with your Unraid API key

Create a key in Settings → Management Access → API Keys (role VIEWER is enough for the file API; use ADMIN if you want the GraphQL proxy to manage the server). The key is validated by Unraid and exchanged for a short-lived session token; it is never stored by the gateway.

These are the shares mounted into the container. Open one to upload files or create folders. Your key's role (VIEWER, ADMIN…) only affects the GraphQL dashboard: file access is decided by the container's volume mounts (read/write or read-only).
