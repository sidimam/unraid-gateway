Connect with your Unraid API key

Create a key in Settings → Management Access → API Keys (role VIEWER is enough for the file API; use ADMIN if you want the GraphQL proxy to manage the server). The key is validated by Unraid and exchanged for a short-lived session token; it is never stored by the gateway.

With an Unraid user and password the gateway applies that user's share permissions (public / secure / private, read or write lists), exactly as over SMB. Without them, access is whatever the container mounts allow.

After connecting: browse and upload files, see who is connected and what is streaming (Activity), try the GraphQL proxy.

These are the shares mounted into the container. Open one to upload files or create folders. Your key's role (VIEWER, ADMIN…) only affects the GraphQL dashboard: file access is decided by the container's volume mounts (read/write or read-only).

Every Unraid Drive installation registers itself when you add the server. Removing a device closes its sessions and the app asks to sign in again (which registers it anew and sends a notification).

Notifications

A new or removed device raises a notification on every configured channel: Unraid's notifications (NOTIFY_UNRAID, needs a key allowed to create them — set NOTIFY_UNRAID_API_KEY to an ADMIN key if yours is VIEWER), e-mail (SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASSWORD, SMTP_FROM, SMTP_TO, SMTP_TLS) and Telegram (TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID). Set them in the container settings.

Unraid API keys (needs an ADMIN key)

List, create, delete and rotate the API keys of your Unraid server through its API. A new key is shown once: copy it into the apps (Edit server or credentials). Rotate = create a replacement, optionally remember it for this web UI and delete the old one.
